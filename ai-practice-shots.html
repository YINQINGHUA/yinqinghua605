本次课堂实践基于 Node.js 本地服务（localhost:8605）搭建的美食主题 AI 应用，共完成 五个任务：在线客服、多平台模型切换、知识库 RAG 问答、图像识别与语音识别。以下为各任务的实际运行截图，点击任意截图可放大查看。

TASK 01 · 在线客服

美食街在线客服「小美」

接入大模型的对话式客服页面：能回答营业时间、招牌菜推荐、配送范围等业务问题；对超出服务范围的提问（写 Python 排序代码、股市行情）礼貌拒答，守住业务边界。

POST http://localhost:8605/api/customer-service
TASK 02 · 多平台切换

服务商在线切换（硅基流动 / 七牛）

同一客服页面右上角下拉框可在大模型服务商之间切换：当前为「硅基流动」，切到「七牛」后无需改代码，后端按所选服务商转发请求，验证了多平台接入层的可替换性。

POST /api/customer-service（服务商：硅基流动 ⇄ 七牛）
TASK 03 · 知识库

知识库文件上传与 RAG 问答

管理页上传《中华美食知识库》.docx 文档，后端自动解析分块入库；问答页基于已上传文档做 RAG 检索增强回答，八大菜系、烹饪技法、经典小吃都能准确作答。

POST /api/kb/upload · GET/DELETE /api/kb/documents · POST /api/customer-service（useKb:true）
TASK 04 · 图像识别

AI 视觉模型图片描述

上传一张图片，视觉模型生成中文描述：对高原峡谷风景图的色彩、光影、构图描述准确细腻，「识别成功」状态与左图右文布局直观展示结果。

POST http://localhost:8605/api/image-recognition
TASK 05 · 语音识别

AI 语音转文字

上传一段 .wav 语音，语音识别模型将其转写为文字，页面提供音频预览播放器与「复制文字」按钮，转写结果「中华美食知识库。」准确无误。

POST http://localhost:8605/api/speech-recognition
