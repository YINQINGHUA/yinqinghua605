原理 · 两个文件

本页没有连网。一份 all.min.css 声明 @font-face， 浏览器按相对路径到 webfonts/ 里取出 woff2 字体；之后每个 <i> 就是一个普通的文字节点——它之所以是图标，只因为换了字体。

这也是字体图标的天性与局限：继承文字的渲染，也能被文字的方式改变； 但一枚字形只有一种颜色、一种形状，想改线条粗细，就得看卷二的矢量做法了。

<!-- ① 引入样式，字体自动跟随 -->
<link rel="stylesheet"
      href="cdn/fontawesome/css/all.min.css">

<!-- ② 类名即字形，码位藏在字体里 -->
<i class="fa-solid fa-gear"></i>

/* ③ 纯 CSS 也可以：伪元素里写字位 */
.yqh_icon::after {
  font-family: "Font Awesome 6 Free";
  content: "\f013";  /* gear */
}
